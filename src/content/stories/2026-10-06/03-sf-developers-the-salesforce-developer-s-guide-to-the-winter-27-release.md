The Winter 27 release centers on AIforce and the Headless Toolkit, which expose platform capabilities through APIs, Model Context Protocol tools, and command line interfaces. A new development plugin for Claude Code integrates Salesforce specific skills and connects to hosted servers for metadata guidance. The update also introduces specialized plugins for managing dev hubs, running DevOps pipelines, and authoring Agentforce agents.

Multi Framework support now includes Angular alongside React, enabling developers to run web applications directly on the platform while inheriting standard security and governance. The Data SDK receives several enhancements, including the ability to package custom data logic as reusable extensions, format currency and dates according to user locales, and pass per request headers for granular cache control.

Developers can embed these external framework applications into Lightning pages using a beta microfrontend component that enables two way communication between the host interface and the embedded app. Distribution and management are streamlined through second generation packaging, App Manager configuration, and performance tracking via Scale Center insights.
