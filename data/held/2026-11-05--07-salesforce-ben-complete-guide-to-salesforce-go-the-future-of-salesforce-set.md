Salesforce Go began as Sales Cloud Go to help Sales Cloud admins enable new features, and its scope now covers all Salesforce feature setup. It is found in the Setup menu, and it is available to users with the View Setup and Configuration permission in several editions with Service Cloud. Additional permissions may still be needed depending on the feature being enabled.

The dashboard groups cards into Agents, Features and Feature Sets, and each Feature Set bundles the features that work toward one outcome, such as the Capture & Auto-Qualify Leads set. Each feature links to Salesforce Help, and includes snapshots, videos and a Copy Details option for sharing with stakeholders. The author walks through turning on Sales Engagement from the dashboard, then configuring access with a Manage button or a Go to Setup button where the task lies elsewhere.

Once a feature is marked Completed, Salesforce Go can also be used to monitor it, manage its configuration, assign permissions and track license consumption where applicable.
